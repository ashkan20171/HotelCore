# Ashkan Hotel Pro — v25

## تغییرات
- اعتبارسنجی یکپارچه فرم‌های اتاق، کارمند و پرداخت با پیام‌های فارسی
- پشتیبانی از اعداد فارسی و عربی در شماره اتاق و تلفن
- جلوگیری از ثبت پرداخت صفر و ورودی‌های نامعتبر قبل از عملیات دیتابیس
- ۹ تست جدید برای اعتبارسنجی، بدون وابستگی به PySide6

## اجرا
```powershell
py -m pip install -r requirements.txt
py main.py
py -m unittest discover -s tests -v
```

پیش از انتقال hotel.db نسخه قبلی، نسخه پشتیبان تهیه کنید. اجرای رابط گرافیکی روی ویندوز در این محیط تأیید نشده است. اعتبارسنجی سمت رابط کاربری جایگزین کنترل دسترسی و اعتبارسنجی در لایه سرویس نیست.
