# Ashkan Hotel Pro — Version 79

Interactive room availability calendar: branch-scoped room and reservation queries, bilingual legend and cells, occupancy KPIs, date-range controls, and double-click a free room/date to open the booking form prefilled with room and dates. Reservation submission still uses the existing service and overlap checks.

Run `python -m unittest discover -s tests -v` and `python main.py`. Qt desktop visuals must be verified on Windows. Back up `hotel.db` before upgrading.
