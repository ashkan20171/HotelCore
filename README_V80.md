# Ashkan Hotel Pro v80

- Weekly, two-week and 30-day occupancy calendar presets.
- Single-click cell details with active booking dates/status.
- Double-click an available cell to initiate a reservation (existing flow preserved).
- Matching bookings respects checkout-exclusive dates and ignores cancellations.
- Run: `python main.py`; tests: `python -m unittest discover -s tests`.
- Back up `hotel.db` before upgrading.
